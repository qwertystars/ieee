# SAR Scene Crops

This directory contains small 512x512 SAR scene crops for the Rivertown demo
region. These are synthetic SAR-like patches (not real Sentinel-1 data) used
for testing the flood mapping pipeline (T18/T19).

## Files

- `sar_crop_pre_flood_512x512.npy` — Pre-flood SAR scene (2-band VV+VH, 512x512)
- `sar_crop_post_flood_512x512.npy` — Post-flood SAR scene (2-band VV+VH, 512x512)
- `sar_crop_post_flood2_512x512.npy` — Second post-flood scene (different orbit)

## Generation

The files are generated by `seed_demo.py` using numpy random noise with
realistic SAR-like statistics (speckle noise, log-normal distribution). They
are NOT real Sentinel-1 data.

## Storage

In production, these crops would be stored in MinIO (S3-compatible object
storage). The seed script attempts to upload them to MinIO if available, but
falls back to local file storage if MinIO is not running. This ensures the
seed works without internet or external services.
